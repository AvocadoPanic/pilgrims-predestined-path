## Phase Goal

**As a** player, **I want to** install the game on my phone or computer and get new versions between games, **so that** it opens like an app and an update never ends a game in progress.

Gap closure, plan 2 of 2. It folds in review warnings WR-02 (the build test does not enforce standing rule 4 or check what docs/PWA.md says it checks) and WR-03 (two empty catch blocks in install.js). Task 1 is the tracer: it proves end to end (vite build, emitted sw.js and icons, build test) that CI now refuses a takeover worker and a transparent install icon, each by a caught mutation. Task 2 documents the two ignored errors.

<objective>
CI fails if a later edit adds worker takeover (clientsClaim) to the service worker, which would break "a game in progress never reloads" (PWA-04, standing rule 4), or ships a transparent 192, 512 or maskable install icon (PWA-01). The two ignored errors in install.js say why ignoring them is safe.

Purpose: these guards protect the update and install promises for every later phase that edits vite.config.js or the icons; the comments help whoever debugs the install row next.
Output: additions to src/build-output.test.js (one assertion, one helper, one test); two catch comments in src/pwa/install.js; docs/PWA.md changes only if the icon header check finds a transparent icon (not expected, see Task 1 step 1).
</objective>
