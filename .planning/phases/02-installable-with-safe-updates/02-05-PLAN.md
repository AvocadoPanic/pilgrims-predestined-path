**As a** player, **I want to** install the game on my phone or computer and get new versions between games, **so that** it opens like an app and an update never ends a game in progress.

Release, step 2 of 2: with the owner's go-ahead, build B (the deploy.yml policy commit plus later documentation commits) goes live while a scripted Edge session holds build A, which makes this release the first live two-deploy update check the ROADMAP requires.
