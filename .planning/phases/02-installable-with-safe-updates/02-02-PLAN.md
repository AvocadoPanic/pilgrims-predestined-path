## Phase Goal

**As a** player, **I want to** install the game on my phone or computer and get new versions between games, **so that** it opens like an app and an update never ends a game in progress.

This plan expands the proven update slice of plan 02-01 into installation: the game's own icons, a manifest a browser accepts as installable, and the install row on the setup screen.

<objective>
A player on Android or desktop Chromium can install the game from an Install button on the setup screen (PWA-01), and a player on iPhone or iPad sees "On iPhone or iPad: tap Share, then Add to Home Screen" (PWA-02); the Home Screen and app icons are the game's gold cross, not a screenshot (D-06 to D-12).

Purpose: SC1 and SC2. The real-device installs happen after the push in plan 02-04; this plan proves everything a local browser and the build test can prove.
Output: scripts/pwa-assets.config.mjs; four committed PNGs in public/; manifest icons; index.html apple-touch-icon and title; src/pwa/install.js with tests; the install row in App.jsx; icon assertions in the build test.

Task order note: Task 1 is the package-legitimacy gate and precedes this plan's tracer only because the tracer's first act is the one-time npx run of a SUS-flagged package. No implementation work precedes the gate.
</objective>
