## Shared Patterns

### Base-path safety
**Source:** `vite.config.js:4` (`base: '/pilgrims-predestined-path/'`) plus `%BASE_URL%` in HTML and relative `url()` in CSS.
**Apply to:** `index.html`, `src/fonts.css`, `build-output.test.js` (the `BASE` constant). Never hard-code the prefix in app code.

### Guard-clause / minimal error style
**Source:** `pilgrims-predestined-path.jsx:333` (`if(ts!=="draw"||di>=deck.length)return;`). Applies only if any new runtime code is written; this phase adds none to the component.

### LF and Write-tool rule
**Apply to:** `deploy.yml`, `.gitattributes`, lockfile. Write via the Write tool, never `sed -i` (banned on this machine) and never a heredoc; `core.autocrlf=true` locally.

### Go-live stops
**Apply to:** the final plan. Two explicit user stops: before `git push`, and before `gh api -X PUT repos/AvocadoPanic/pilgrims-predestined-path/pages -f build_type=workflow`. Then `gh workflow run deploy.yml` and the live curl checks.
